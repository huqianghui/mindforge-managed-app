## 常见"找不到"

| 现象 | 原因 |
|---|---|
| Copilot Studio 首页没有 Connector 菜单 | Connector 只在 agent / workflow / app 的编辑界面里，作为"工具"或"数据源"添加 |
| admin center 的 Environments 里没有 Connector | 环境页管环境本身；连接在 make.powerapps.com，策略在 Security → Data and privacy |
| Connections → New connection 搜 "Custom" 搜不到自定义 Connector | 那里是现成 Connector 的目录；自定义 Connector 是另一个页面 |
| More 面板全展开也没有 Custom connectors | More 只列已固定项，要点底部 **Discover all** |
| Connections 页看不到刚建的连接 | 列表懒加载，往下滚；或者右上角环境选错了 |
| Data policy 页是空的 | 普通账号无权查看租户策略（策略存在，只是看不到） |
